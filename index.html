Production work

Systems in daily use by real operations teams. The code belongs to the companies that paid for it, so it is described here rather than shown — the open-source demos below rebuild the interesting parts from scratch on invented data.

Accounting data pipelines

GSI Group

  • Two-way integration between Accurate Online's accounting API and Google BigQuery: token plus per-request signature auth, scheduled sync, idempotent loads.
  • Paginated by document id, not by date. A date filter silently skipped records that had been back-dated after creation; sweeping by id closed the gap, and completeness is now verified against the source API's own row count rather than assumed.
  • FIFO cost-of-goods engine reconstructing per-item cost from inventory layers, validated against the accounting journal as referee — 963 of 963 documents matched, where the spreadsheet it replaced matched 49.
  • Read-only XML-RPC bridge into Odoo for downstream reconciliation.

Multi-module ERP

Zuliya Group

  • Dozens of modules in daily production across several business lines: approval workflows, attendance with photo and GPS capture, asset register, cash handling, executive dashboards.
  • Permissions scoped per module and per region, not globally — so one workflow definition serves branches with different rules instead of forking the codebase per branch.
  • Rewrote an executive dashboard's aggregation in SQL after the gateway kept killing it at 86.5 seconds. It runs in 6.0 seconds.
  • Photo-to-data pipeline reading handwritten field forms from phone photos: perspective correction, grid segmentation, per-cell recognition with a voting ensemble — tuned for zero wrong readings rather than maximum coverage, because a silently wrong number costs far more than a blank one.

Retail point-of-sale & stock

Optik Rizki Eye Plus

  • POS and inventory across dozens of branches: sales, inter-branch stock transfers with scan-based receipt confirmation, and an append-only stock movement trail.
  • Moved price resolution to the server after finding it trusted a price posted by the browser — when the client-side event didn't fire, invoices saved at zero with no warning. An invalid master price now blocks the save outright.
  • Branch-scoped catalogue sync, delivery notes, and payment-consistency guards.

Go services & AI tooling

Various

  • Two Go backends in production: an internal HR and candidate-assessment platform (React + TypeScript + Vite frontend, PostgreSQL with enforced row-level security) and a mobile inventory system behind nginx and systemd.
  • Ported a legacy scoring engine and proved the port correct before trusting it: an independent re-implementation diffed against the new service across 300 real records — zero differences.
  • Natural-language query tool over BigQuery: a deterministic engine answers known question shapes first, a tiered set of language models handles the rest, and causal or hypothetical questions are flagged so a model's reasoning is never presented as measured fact.
  • React Native inventory app with device-camera capture, sharing one backend with its web counterpart through database views instead of duplicated query logic.
